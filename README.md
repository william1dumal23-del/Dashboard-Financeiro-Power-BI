📊 Dashboard Financeiro | Power BI

Sobre o projeto

Este projeto foi desenvolvido no Microsoft Power BI, com o objetivo de transformar dados comerciais e financeiros em indicadores visuais que facilitem o acompanhamento de resultados e a tomada de decisões.

Funcionalidades

O dashboard possui três páginas interativas:

Visão Geral: apresenta os principais indicadores de desempenho do negócio.

Produtos: permite analisar o desempenho das vendas e comparar produtos.

Detalhes: oferece uma análise mais específica dos dados.

O relatório conta com gráficos interativos, filtros, botões de navegação e indicadores para alternar visualizações.

Tecnologias utilizadas

Microsoft Power BI

Power Query

DAX

Análise e visualização de dados

Objetivo

Facilitar a identificação de tendências, o acompanhamento de indicadores e a análise do desempenho comercial por meio de um relatório visual e interativo.
